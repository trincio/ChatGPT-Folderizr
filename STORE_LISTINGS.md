## Mozilla Add-ons

### Name

Folderizr

### Summary

Visually group ChatGPT sidebar conversations by bracketed title prefix.

### Description

Folderizr is a simple open-source browser extension that visually organizes the ChatGPT sidebar. If a conversation title starts with a bracketed folder name, such as `[Work] Project update`, Folderizr groups it under a local visual folder named `Work`.

Folderizr does not rename ChatGPT conversations, modify conversation data server-side, export chats, scrape content, or call private or undocumented endpoints. It only changes the local visual layout of the sidebar while enabled.

Folderizr depends on ChatGPT's web UI and may break if that UI changes.

### Permissions

- `storage`: remembers the local enable/disable preference.

The content script runs only on `https://chatgpt.com/*` and `https://chat.openai.com/*`.

### Data Use

Folderizr does not collect data, transmit data, track users, profile users, use analytics, show ads, use affiliate links, load remote code, or use a backend service.

## Chrome Web Store

### Name

Folderizr

### Short Description

Visually group ChatGPT sidebar chats by title prefix.

### Detailed Description

Folderizr visually groups ChatGPT sidebar conversations whose visible titles start with a bracketed folder prefix.

Example:

```text
[Work] Project update
[Music] Synth setup
```

Folderizr displays those chats under local visual folders named `Work` and `Music`. The underlying ChatGPT conversation titles are not changed by the extension.

Independent open-source browser extension. Not affiliated with, endorsed by, or sponsored by OpenAI.

Known limitation: Folderizr depends on ChatGPT's web UI and may break if the UI changes.

### Permissions

- `storage`: used only to remember whether Folderizr is enabled or disabled.

Folderizr runs only on `https://chatgpt.com/*` and `https://chat.openai.com/*`.

### Privacy

Folderizr does not collect, transmit, sell, share, track, or profile user data. It has no ads, analytics, telemetry, affiliate links, remote logging, backend services, or remote code.
