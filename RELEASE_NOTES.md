# Folderizr 1.1.0 Release Notes Draft

Folderizr 1.1.0 prepares the extension for a safer, privacy-preserving, cross-browser release.

## Highlights

- Supports both `https://chatgpt.com/*` and `https://chat.openai.com/*`.
- Uses the product name Folderizr, with ChatGPT referenced descriptively.
- Includes the required independent-project disclaimer.
- Keeps permissions minimal with only `storage` for the local enable/disable preference.
- Replaces aggressive polling with `MutationObserver`-based sidebar updates.
- Keeps folder organization local and visual only.
- Preserves native ChatGPT sidebar controls instead of hiding or disabling them.
- Adds privacy, testing, changelog, and store listing documentation.

## Privacy

Folderizr does not collect, transmit, sell, share, track, profile, analyze, export, or scrape user data. It has no ads, analytics, telemetry, affiliate links, remote logging, backend service, or remote code.

## Known Limitation

Folderizr depends on ChatGPT's web UI and may need updates if the ChatGPT sidebar markup changes.

## Disclaimer

Independent open-source browser extension. Not affiliated with, endorsed by, or sponsored by OpenAI.
