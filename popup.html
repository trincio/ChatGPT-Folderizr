Visually group ChatGPT sidebar chats whose titles start with a folder prefix, such as [Work] Project update.

Independent open-source browser extension. Not affiliated with, endorsed by, or sponsored by OpenAI.

Folderizr only changes the local page view. It does not rename conversations, collect data, transmit data, add analytics, or use remote code.

It depends on ChatGPT's web UI and may break if that UI changes. If you disable Folderizr, the ChatGPT page reloads to restore the original sidebar layout.
